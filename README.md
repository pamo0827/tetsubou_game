# 大車輪てつぼうくん (Daisharin Tetsubou-kun)

タイミングよくボタンを押して鉄棒で加速し、大空へ飛び出そう！
物理演算を取り入れた、シンプルながら奥深い飛距離競争ゲームです。

## ゲームプレイ

**[Webで遊ぶ (クリックしてスタート)](https://pamo0827.github.io/tetsubou_game/)**

※ PCブラウザ推奨（キーボード操作が必要です）

## 操作方法

- **SPACEキー**:
    - **加速**: 選手が伸縮して回転を加速させます。
    - **コツ**:
        - 上昇中（↑）に体を **縮める（キーを押す）**
        - 下降中（↓）に体を **伸ばす（キーを離す）**
        - タイミングが合うと「PERFECT!!」と表示され、ぐんぐん加速します！

- **ENTERキー**:
    - **ジャンプ**: 鉄棒から手を離して飛び出します。
    - **コツ**: 十分にスピードがついたら、斜め上（約45度）を狙ってリリース！

- **Rキー**: リトライ
